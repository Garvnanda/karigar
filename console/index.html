What is the owner key?

A private password for this page only. You choose it once and save it on the server as KARIGAR_OWNER_TOKEN (Render: your service, then Environment). Customers never need it; the studio works without it. Nonilion uses a different key, KARIGAR_API_KEY, and the laptop worker a third, KARIGAR_WORKER_TOKEN, so a leaked one never opens the others.
